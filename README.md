\# Проект: Управление событиями (Event Manager) — Спринт 1



API для создания и получения событий с валидацией бизнес-логики (дата окончания должна быть строго позже даты начала).



\## Технологии

\- \*\*.NET 10\*\*

\- ASP.NET Core Web API

\- C# 11+



\## Требования для запуска

\- Установленный \*\*.NET 10 SDK\*\*

\- Браузер или Postman/curl для тестирования



\## 🚀 Быстрый старт

Чтобы запустить проект локально, выполните следующие шаги:

Убедитесь, что у вас установлен .NET SDK (версии 8.0 или выше).

Откройте терминал в корне проекта (там, где лежит файл .csproj).

Запустите проект командой: bash dotnet run

После запуска сервер сообщит адрес (Now listening on: https://localhost:7017 Now listening on: http://localhost:5029). Откройте его в браузере или используйте примеры ниже.



\## 🧪 Примеры запросов для проверки

\### ✅ Успешное создание события

Проверяет: наличие полей и логику EndAt > StartAt.

Команда: bash curl -X POST 'http://localhost:5029/events' \\ -H 'accept: \*/\*' \\ -H 'Content-Type: application / json'\\-d '{"id": 105,"title":"Labour Day","description": "string", "startAt":"2027-05-01T00:00:00","endAt":"2027-05-02T00:00:00"}'



Ожидаемый ответ: 200 OK с данными созданного события.



\### ❌ Ошибка валидации: дата окончания раньше начала

Этот запрос должен упасть с ошибкой 400, так как сработает твой кастомный атрибут \[GreaterThan].

Команда: curl -X POST 'http://localhost:5029/events' \\

&#x20; -H 'accept: \*/\*' \\

&#x20; -H 'Content-Type: application/json' \\

&#x20; -d '{"id": 105,"title":"Labour Day","description": "string", "startAt":"2027-05-01T18:00:00","endAt":"2027-05-01T10:00:00"}'



Ожидаемый ответ: 400 Bad Request с сообщением: "Дата окончания должна быть позже даты начала." в поле errors.



\### ❌ Ошибка валидации: пустое название Проверяет работу атрибута \[Required].

Команда: curl -X POST 'http://localhost:5029/events' \\

&#x20; -H 'accept: \*/\*' \\

&#x20; -H 'Content-Type: application/json' \\

&#x20; -d '{"id": 105,"title":"","description": "string","startAt":"2027-05-01T00:00:00","endAt":"2027-05-02T00:00:00"}'



Ожидаемый ответ: 400 Bad Request с ошибкой про обязательное поле Title.



\### ✅ Получение списка событий

Команда: curl -X GET 'http://localhost:5029/events' \\

&#x20; -H 'accept: \*/\*'

Ожидаемый ответ: 200 OK со списком событий в формате DTO (без лишних полей вроде IsDeleted или RowVersion).
