# \# Проект: Управление событиями (Event Manager) — Спринт 1

# 

# API для создания и получения событий с валидацией бизнес-логики (дата окончания должна быть строго позже даты начала).

# 

# \## Технологии

# \- .NET 10

# \- ASP.NET Core Web API

# \- Entity Framework Core

# \- C# 11+

# 

# \## Требования для запуска

# \- Установленный .NET 10 SDK 

# \- Браузер или Postman/curl для тестирования

# 

# \## 🚀 Быстрый старт

# 

# \### 1. Запуск проекта bash dotnet run

# После успешного запуска ты увидишь сообщение вроде: Now listening on: https://localhost:7001 Now listening on: http://localhost:5001

# Запомни свой порт (например, 7001) — он понадобится для запросов.

# 🧪 Примеры запросов (для проверки)

# \### ✅ Успешное создание события Проверяет: наличие полей и логику EndAt > StartAt.

# bash curl -X POST http://localhost:5001/api/events \\ -H "Content-Type: application/json" \\ -d "{ \\"title\\": \\"Конференция по C#\\", \\"startAt\\": \\"2024-10-25T10:00:00\\", \\"endAt\\": \\"2024-10-25T18:00:00\\" }" Ожидаемый ответ: 200 OK с данными созданного события.

# \### ❌ Ошибка валидации: дата окончания раньше начала Этот запрос должен упасть с ошибкой 400, так как сработает твой кастомный атрибут \[GreaterThan].

# bash curl -X POST http://localhost:5001/api/events \\ -H "Content-Type: application/json" \\ -d "{ \\"title\\": \\"Тест неверных дат\\", \\"startAt\\": \\"2024-10-25T18:00:00\\", \\"endAt\\": \\"2024-10-25T10:00:00\\" }" Ожидаемый ответ: 400 Bad Request с сообщением: "Дата окончания должна быть позже даты начала." в поле errors.

# \### ❌ Ошибка валидации: пустое название Проверяет работу атрибута \[Required].

# bash curl -X POST http://localhost:5001/api/events \\ -H "Content-Type: application/json" \\ -d "{ \\"startAt\\": \\"2024-10-25T10:00:00\\", \\"endAt\\": \\"2024-10-25T18:00:00\\" }" Ожидаемый ответ: 400 Bad Request с ошибкой про обязательное поле Title.

# \### ✅ Получение списка событий bash curl http://localhost:5001/api/events Ожидаемый ответ: 200 OK со списком событий в формате DTO (без лишних полей вроде IsDeleted или RowVersion).
